# Dominique Rigault, consultant en données

J'aide les PME et ETI de Normandie à tirer parti de leurs données, du diagnostic jusqu'aux tableaux de bord utilisés au quotidien.
Entrepreneur salarié de la CAE Astrolabe.

## Ce que je propose

- **Audit** : diagnostic data, feuille de route progressive, cas d'usage
- **Réalisation** : mise en qualité des données, interconnexion des systèmes, entrepôt de données, indicateurs et outils décisionnels
- **Accompagnement** : RGPD, gouvernance des données, acculturation, documentation et formation

## Outils

Python (Pandas, scikit-learn), SQL, Power BI (DAX), Streamlit, FastAPI, Git et GitHub, SIG et géomatique

## Projets

- [FrigeoServices_traitement](https://github.com/dominique-rigault/FrigeoServices_traitement) : cas d'étude sur une PME fictive de maintenance frigorifique, à partir de données fabriquées (nettoyage, base SQL, indicateurs, Power BI), en cours
- [accessibilite-centralites-mrn](https://github.com/dominique-rigault/accessibilite-centralites-mrn) : analyse de l'accessibilité bas carbone aux centralités de la Métropole Rouen Normandie
- [SeineCrops](https://github.com/dominique-rigault/SeineCrops) : projet de formation en géomatique, secteur agricole
